# Зависшие сессии / «пользователь уже работает в системе»

**Система:** 1С
**Категория:** Сессии
**Ключевые слова:** сессия, завис, пользователь уже работает, завершить сеанс

## Симптомы

- При входе появляется сообщение «Пользователь уже работает в системе».
- Пользователь не может начать сеанс, хотя не использует 1С.
- В списке сессий много активных сессий одного пользователя.

## Причины

- Аварийное завершение клиента 1С (обрыв сети, закрытие процесса).
- Зависшие фоновые задания или веб-клиент.
- Долгое время бездействия сессии без таймаута.

## Решение

1. Получить список активных сессий и найти нужного пользователя.
2. Проверить, действительно ли сессия зависла (время активности).
3. Завершить зависшие сессии пользователя администратором.
4. Повторить вход пользователя.
5. Настроить таймаут неактивных сессий при необходимости.

## Действия, которые могут понадобиться

- Получить список активных сессий.
- Завершить сессию пользователя.
