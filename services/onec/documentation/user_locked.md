# Пользователь заблокирован: превышено число неудачных попыток

**Система:** 1С
**Категория:** Пользователи
**Ключевые слова:** заблокирован, попытки входа, пароль, блокировка

## Симптомы

- При входе в 1С появляется сообщение «Пользователь заблокирован».
- Пользователь не может войти в систему, хотя пароль верный.
- В журнале регистрации — записи о неудачных попытках входа.

## Причины

- Пользователь многократно вводил неверный пароль (порог — по настройкам).
- Служебный/фоновый процесс вводит устаревший пароль.
- Включена политика безопасности информационной базы (ограничение попыток).

## Решение

1. Подтвердить статус блокировки в конфигураторе/сервисном инструменте.
2. Разблокировать пользователя (администратором).
3. Сбросить пароль пользователя и выдать временный.
4. Проверить, не подключён ли к базе процесс со старым паролем (см. «Зависшие сессии»).
5. Напомнить пользователю про корректный ввод и регистр пароля.

## Действия, которые могут понадобиться

- Разблокировать пользователя.
- Сбросить пароль пользователя.
- Получить список активных сессий.
