# База не может быть захвачена монопольно

**Система:** 1С
**Категория:** База данных
**Ключевые слова:** монопольно, exclusive, блокировка базы, захват базы

## Симптомы

- Ошибка «База данных не может быть захвачена монопольно».
- Не запускается обновление конфигурации или выгрузка данных.
- Сообщение появляется при попытке административных операций.

## Причины

- Активные сессии пользователей или фоновые задания подключены к базе.
- Не завершены сеансы после аварийного завершения клиента.
- Другая административная операция уже выполняется.

## Решение

1. Получить список активных сессий (см. «Зависшие сессии / пользователь уже работает»).
2. Отключить пользователей или попросить их завершить работу.
3. Завершить зависшие сессии администратором.
4. Повторить операцию в монопольном режиме.

## Действия, которые могут понадобиться

- Получить список сессий.
- Завершить сессию пользователя.
