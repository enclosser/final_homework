# Задержка доставки / письмо не доставлено (NDR)

**Система:** Exchange
**Категория:** Почта
**Ключевые слова:** NDR, задержка, очередь, недоставлено, delay

## Симптомы

- Пользователь получил уведомление о недоставке (NDR / delivery report).
- Письмо долго не доходит, статус «Задержка доставки».
- Коды DSN 4.x / 5.x в отчёте о доставке.

## Причины

- Переполнение очереди отправки на сервере Exchange.
- Проблемы с DNS: не резолвится MX целевого домена.
- Превышены лимиты размера сообщения (MaxSendSize / MaxReceiveSize).
- Получатель не существует или ящик получателя переполнен.
- Внешний почтовый сервер временно недоступен.

## Решение

1. Прочитать текст NDR — он указывает причину (код DSN, сообщение).
2. Проверить очереди на сервере: количество сообщений, статус (Retry, Frozen).
3. Проверить DNS/маршрутизацию до целевого домена.
4. Проверить лимиты размера сообщения для отправителя и получателя.
5. При Frozen-сообщениях — «разморозить» очередь; при Retry — подождать или перезапустить транспортную службу.

## Действия, которые могут понадобиться

- Получить статус очередей.
- Разморозить / очистить очередь.
- Перезапустить транспортную службу.
