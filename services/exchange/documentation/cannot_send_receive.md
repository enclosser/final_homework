# Не отправляются и не приходят письма

**Система:** Exchange
**Категория:** Почта
**Ключевые слова:** не отправляется, не приходит, нет почты, send receive

## Симптомы

- Пользователь не может отправить письмо (ошибка в Outlook).
- Письма не приходят, даже от внутренних сотрудников.
- В статусе отправки — «Ожидает отправки».

## Причины

- Проблема с подключением Outlook к серверу Exchange (неверный профиль).
- Почтовый ящик отключён (isDisabled).
- Письма зависли в очереди на сервере (см. «Задержка доставки / NDR»).
- Превышены лимиты отправки (политики).
- Ошибки в DNS/маршрутизации для внешних писем.

## Решение

1. Проверить статус почтового ящика: включён ли, не скрыт ли из адресной книги.
2. Проверить состояние очередей отправки на сервере.
3. Пересоздать профиль Outlook или подключить заново.
4. Проверить политики отправки/получения (Receive Connector, Send Connector).
5. Проверить размер ящика (см. «Почтовый ящик переполнен»).

## Действия, которые могут понадобиться

- Проверить статус почтового ящика.
- Посмотреть состояние очередей.
- Перезапустить транспортную службу.
