# Outlook постоянно запрашивает пароль

**Система:** Exchange
**Категория:** Клиент
**Ключевые слова:** запрос пароля, prompt password, профиль, учётные данные

## Симптомы

- Outlook периодически выводит окно запроса пароля.
- После ввода пароль запрашивается снова.
- Ошибка о невозможности подключения к серверу.

## Причины

- Истёк или был изменён пароль пользователя.
- Устаревшие учётные данные в диспетчере учётных данных Windows.
- Неверные настройки Autodiscover/профиля Outlook.
- Подключение через устаревшие конечные точки (RPC over HTTP).
- Учётная запись заблокирована в каталоге (см. LDAP «Учётная запись заблокирована»).

## Решение

1. Проверить, актуален ли пароль пользователя в домене.
2. Очистить сохранённые учётные данные Windows (Диспетчер учётных данных → Очистить учётные данные Windows).
3. Проверить настройки Autodiscover и корректность URL сервера Exchange.
4. Пересоздать профиль Outlook.
5. Проверить, не блокирует ли антивирус/брандмауэр подключение.

## Действия, которые могут понадобиться

- Проверить статус учётной записи в каталоге.
- Принудительно обновить учётные данные.
