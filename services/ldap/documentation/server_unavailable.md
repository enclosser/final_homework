# LDAP-сервер недоступен / таймаут подключения

**Система:** LDAP
**Категория:** Инфраструктура
**Ключевые слова:** недоступен, timeout, connection, offline, таймаут

## Симптомы

- Сервис/приложение не может установить соединение с каталогом.
- Ошибки «Connection refused», «Timeout», «The LDAP server is unavailable».
- Пользователи массово не могут войти в домен.

## Причины

- Контроллер домена перезагружается или недоступен по сети.
- Неверный адрес/порт LDAP (по умолчанию 389, LDAPS — 636).
- Превышен лимит соединений или исчерпаны ресурсы сервера.
- Сбой службы NTDS или сети между клиентом и сервером.

## Решение

1. Проверить доступность сервера: ping, проверка порта 389/636.
2. Проверить работоспособность службы NTDS на контроллере домена.
3. Убедиться, что в настройках указан корректный адрес и порт.
4. Проверить сетевые политики/брандмауэр между клиентом и сервером.
5. При наличии нескольких контроллеров — переключиться на другой (DNS).

## Действия, которые могут понадобиться

- Проверить доступность сервиса.
- Получить список контроллеров домена.
