# Учётная запись заблокирована

**Система:** LDAP
**Категория:** Аутентификация
**Ключевые слова:** блокировка, locked out, account lockout, попытки входа

## Симптомы

- Пользователь не может войти, хотя пароль верный.
- В журнале событий: 4740 «Учётная запись пользователя заблокирована».
- Сообщение «Учётная запись заблокирована» / «Account locked out».

## Причины

- Политика блокировки: превышено число неудачных попыток входа.
- Автоматические сценарии/служебные учётные записи вводят неверный пароль.
- Устаревший пароль, сохранённый в учётных данных на устройстве пользователя.

## Решение

1. Подтвердить блокировку: посмотреть атрибут lockoutTime и счётчик badPwdCount.
2. Разблокировать учётную запись (обнулить lockoutTime и badPwdCount).
3. Предупредить пользователя о подборе пароля; при необходимости сменить пароль.
4. Для сервисных учёток — усилить пароль и ограничить источники входа.

## Действия, которые могут понадобиться

- Проверить статус блокировки.
- Разблокировать учётную запись.
- Сбросить пароль.
