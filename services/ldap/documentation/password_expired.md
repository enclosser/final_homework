# Истёк срок действия пароля

**Система:** LDAP
**Категория:** Аутентификация
**Ключевые слова:** пароль, срок действия, expired, must change password

## Симптомы

- Пользователь входит впервые за долгое время, но система требует смены пароля.
- Ошибка «Пароль истёк. Необходимо сменить пароль».
- Атрибут pwdLastSet устарел относительно политики срока действия паролей.

## Причины

- Включена политика срока действия пароля (обычно 42–90 дней).
- Пользователь давно не менял пароль.
- Администратор принудительно пометил пароль на смену при следующем входе.

## Решение

1. Проверить, истёк ли срок: сравнить pwdLastSet с политикой паролей домена.
2. Выдать пользователю временный пароль с пометкой «сменить при первом входе».
3. При необходимости установить принудительную смену пароля при следующем входе.
4. Напомнить пользователю требования к сложности пароля.

## Действия, которые могут понадобиться

- Сбросить пароль.
- Установить принудительную смену пароля при следующем входе.
