# Пользователь не найден в каталоге

**Система:** LDAP
**Категория:** Каталог
**Ключевые слова:** пользователь не найден, not found, нет учётной записи, объект

## Симптомы

- При входе система сообщает, что пользователь не существует.
- Поиск по имени в каталоге не возвращает результатов.
- Ошибка «The user name could not be found».

## Причины

- Опечатка в имени пользователя или выбран неверный домен.
- Учётная запись создана в другом подразделении/лесу.
- Учётная запись удалена или перемещена.
- Задержка репликации между контроллерами домена.

## Решение

1. Уточнить точное имя пользователя и домен.
2. Выполнить поиск по sAMAccountName, UPN, e-mail, ФИО.
3. Проверить, не находится ли объект в «корзине» AD — при необходимости восстановить.
4. При необходимости создать учётную запись заново.
5. Если данные не синхронизированы — дождаться репликации или форсировать её.

## Действия, которые могут понадобиться

- Найти пользователя в каталоге.
- Восстановить / создать учётную запись.
